Preference Collector
Rate an assistant reply with the thumbs on the message. Edit a reply first, then like it to save an edited preference pair. Swipe to a better reply and like it to save a swipe pair. Shift-click a thumb for failure tags + a note; Alt-click clears a rating. An empty swipe can be disliked and is exported as an empty sample.
Dataset folder
Every rating is merged into one cumulative, model-agnostic JSONL file on the server: data/<user>/files/preference-dataset.jsonl (that is the Data Bank folder). It is flat because the upload API rejects subdirectories. Records use plain role/content messages with no chat-template tokens, so the same file trains on Qwen, Gemma, DeepSeek, Llama, ... - the trainer applies that model's template.
